# SliceAI · HTML 交互设计稿

直接打开 `index.html`，无需安装依赖，也不请求网络服务。配套 CSS、JavaScript 和素材需要保持目录结构。

## 设计方向

- 暖石墨灰工作台，杏色用于选中与主操作，灰绿色用于内容依据。
- 以候选、视频和原文为中心，避免装饰性数据面板、大面积渐变和发光效果。
- 三栏工作区 + 整场时间轴；较窄窗口自动重排。
- 适用于虚拟主播聊天：搞笑整活、故事分享、弹幕互动、观点金句。

## 可以体验

候选切换、分类筛选、勾选与全选、转写搜索、弹幕和推荐依据切换、时间定位、模拟播放、剪辑入出点调整、时间轴缩放、素材选择弹窗、分析偏好、导出设置、下载 JSON 剪辑清单。

所有示例来自人工编写的数据；播放仅推进时间和示例字幕，图片不会动，没有音频。导入仅展示所选文件名。API、本地 ASR、真实视频剪辑、字幕导出尚未接入。设置和更改仅在当前页面会话内保留。

## 已确认的产品边界

1. Windows 客户端，主要剪辑虚拟主播聊天录播。
2. 时长与成片形式由用户选择。
3. ASR 使用本地模型；精彩内容分析使用 API。
4. 与 BilibiliLive 完全独立，不读取其 Key、配置或数据库，不修改其项目和素材。
5. 本地 ASR 按需启动，任务完成后释放；长录播按块处理。设计稿不展示虚构内存实测值。
