# SliceAI · 第二版 HTML 交互设计稿

直接打开 `index.html` 即可使用，不依赖构建工具或外部网络服务。需要保留同目录的 CSS、JavaScript 和 assets。

## 这次重做的方向

SliceAI 是全自动录播切片工具。用户导入长录播，程序根据 ASR 转写和可选弹幕定位精彩部分，自动确定片段边界，再输出独立片段或合集。

首页不提供播放器、时间轴、转写编辑器或手动剪辑面板。只包含素材导入、简洁的切片偏好和最近任务。

视觉采用白色、浅中性灰、石墨色文字与少量蓝色强调。没有大面积渐变、发光装饰和多余的统计面板。

## 三个主要状态

1. **导入**：选择或拖入长录播，可选字幕、弹幕；设置每段时长、内容偏好、独立片段或合集，以及自动导出。
2. **处理**：本地转写、AI 定位、自动剪辑和导出。支持离开页面后继续演示，也可以取消。
3. **结果**：展示已经定位的精彩片段，支持预览、分类筛选、导出全部或选中内容。没有剪辑面板。

点击“试试示例录播”，再点击“开始自动切片”，即可体验约 12 秒的完整演示。

## 演示边界

- 这是设计稿，未实现真实 ASR、API、FFmpeg、视频播放或视频导出。
- 真实文件选择只读取文件名与大小，不读取内容、不上传。
- 即使选择真实视频，演示任务仍使用独立的内置示例，并明确提示两者无关。
- “自动导出”演示不会产生实际视频文件。结果页可以下载 JSON 示例剪辑清单。
- 进度速度、历史任务、精彩片段、转写摘录均为演示数据。
- 所有状态仅保留于当前页面会话。

## 已确认的产品约束

- Windows 客户端，主要处理虚拟主播聊天录播。
- 本地 ASR 转写；精彩内容分析必须使用 API。
- 与 BilibiliLive 完全独立；不读取其密钥、配置和数据库，不修改其文件。
- 用户选择成片时长、内容偏好以及独立片段或合集。
- 按块处理长录播，模型按需运行、完成后释放；默认限制同时运行的任务数。

## 文件

- `index.html`：页面结构。
- `styles.css`：全新视觉样式及自适应布局。
- `app.js`：自动切片流程演示与各页面交互。
- `assets/stream-room.png`：内置 imagegen 生成的原创示例画面，仅用于任务和结果缩略图。
- `image-prompt.txt`：素材原始生成提示词。
- `archive-v1/`：上一版设计稿备份。

所有文本文件使用 UTF-8 无 BOM 编码。
