# 全面复核整改记录（2026-09-30）

本轮完成源码整改、回归与构建流程补齐，保持既有便携客户端和安装包。新增行为需从当前源码构建后使用。

| 复核问题 | 处理结果 |
| --- | --- |
| 音频起点、非零 PTS 与丢包间隙使转写错位 | 视频时间零点统一；ASR、试听、细剪、预览、导出与抽帧共用时间映射；保留音频间隙 |
| 多音轨处理与播放不一致 | 导入时显式选音轨；任务、模型输入、缓存、导出绑定选择；需转换时生成所选轨道的播放版本 |
| 更换录播仍沿用旧字幕/弹幕 | 素材身份变化时清除附件和音轨选择，提供可见移除按钮 |
| 工作进程退出后任务卡住 | 回收进程并恢复对应任务/项目为可重试状态；保留版本和已有成片 |
| 异步响应覆盖后来打开的项目 | 所有工作区异步操作校验项目与打开代次；后台操作使用原请求项目 |
| 改区间丢掉核对字幕和手改文字 | 保存完整源时间字幕与局部覆盖；扩大范围补回源字幕，字幕草稿按项目/版本自动恢复 |
| 切点字幕仍包含删掉的完整句 | 只重新识别保留音频的受影响区间；保留完整手改句，跨区间合并/部分恢复也重新校验；保留未核对提醒 |
| 缓存导出绕过后来的来源排除 | 每次预览/导出都重新通过来源门禁，包括已缓存媒体 |
| 单引号路径、奇数尺寸渲染失败 | 字幕使用固定相对路径及工作目录；生成偶数输出尺寸；失败/取消清理生成中转文件 |
| 调整降音乐强度重复运行分离模型 | 独立缓存 speech stem，强度变化仅混音；绑定文件版本、音轨、事件与模型身份 |
| 缓存空间缺少预算 | 16 GiB 软预算与处理前空间估算；仅清理校验过的自有 WAV，保护版本、试听引用和成片；拒绝链接越界 |
| 长事件 API 上下文/输出容易截断 | 细剪、连续性、精选、重复讲述分批传输并跨批归并；证据限制在本批原文/输入证据，逐段覆盖校验；保留完整源故事范围 |
| 干净源码依赖本机旧模型/测试数据 | 固定模型清单、hash、许可证、离线导入/显式下载；开发环境识别仓库内准备的 ASR 模型；正式流程与历史验收脚本分别说明 |
| 草稿、后台任务与工程质量基线不足 | 字幕本地草稿、全局队列/定位任务、分层 CI、固定合成渲染与人工标注评分工具 |

## 已测证据

25 秒用户认可的笑声原声使用既有 BandIt Plus 权重、CPU 和现有动态线程策略运行。首次分离 126.531 秒，采样进程树工作集峰值 965.039 MiB；相对认可分离基线最大样本误差 5.066e-7、相关性 0.9999999999999714。同一 stem 调整强度到 0.5 为 2.140 秒、201.465 MiB；未再执行模型分离，混音逐样本符合原公式。模型、原声、认可基线与已有客户端均未替换。该结果只代表此样本与本机负载。

干净暂存源码导出目录完成 npm ci、生产构建、前端回归、模型下载 dry-run、模型下载/离线导入/hash 及评分 fixture 回归。合成媒体通过真实预览与导出：24 秒源素材生成 10 秒成片，时长误差 0.010667 秒，字幕元数据边界误差 0。该次干净环境未安装资源采样依赖，资源指标明确标为未测。

最终回归共 132 项通过：后端主环境执行 108 项，其中 103 项通过、5 项音频运行时测试在独立音频环境执行并通过；前端 12 项，资产与评分脚本 12 项。干净源码的后端合集通过，生产前端构建与 Rust 检查通过。GitHub Actions 配置已补齐，本地验收不代表云端工作流已经执行。

## 验收边界

没有重打包或替换现用客户端。固定下载清单和 fixture 验证不等于已执行全新环境的大权重下载及完整安装包构建。

没有调用真实云端 AI，也没有完成整场长录播人工标注。真实故事召回/误选、细剪语义误删、声学字幕同步和整场峰值资源，仍应依照 [验收定义](acceptance.md) 进行发布验收；不能把 mock 与短样本解释为这些质量指标已经通过。
