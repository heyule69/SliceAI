# 串行任务队列

转写、来源复核、细剪、声音分离和导出共用桌面端的一条重任务队列。状态栏在有任务时写「一次一项重任务」，队列窗口也说明后面的任务会等待。

实现在 `src-tauri/src/main.rs`：`work_lock` 包住 `run`、`export`、`recheck`、细剪自动处理、预览转码和声音试听。不在这张表里的读取、设置和直接可播的预览不占这把锁。取消只停止当前任务，队列里的下一项仍按顺序开始。

现在不并行跑这些重任务。字词对齐、BandIt 分离和转写都会占大量内存；同时开两项容易把还没测过的机器打满，也让取消和崩溃恢复变难核对。

以后如果要并行，只考虑把「不跑模型的兼容预览」从重任务锁里拆出去，并且先用真实长录播量过峰值内存。不要同时跑 ASR、字词对齐和 BandIt。这次没有改执行顺序。
