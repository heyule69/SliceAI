# SliceAI

Windows 本地录播自动切片工具。导入长录播，选择内容偏好，自动定位精彩内容并导出独立片段或合集。首页没有时间线或手动剪辑面板。

## 使用

安装版：`release/SliceAI_0.1.2_x64-setup.exe`。

免安装版：运行 `release/SliceAI/SliceAI.exe`，请保留旁边的 `worker` 文件夹。支持 Windows 10 / 11 x64，需要 Microsoft Edge WebView2 Runtime；安装程序可以在缺少时下载运行时。无需安装 Python、Node.js 或 FFmpeg。

1. 点击左下角 **设置 → AI 服务**，填写自己的 API 地址、模型名称和 API Key，再点击“保存并测试”。支持 OpenAI 兼容的 Chat Completions 接口。默认使用 DeepSeek Flash；官方 DeepSeek 接口显式关闭思考模式。服务商不支持 JSON 模式时可以关闭该选项。
2. 没有现成字幕时，在设置中下载 SenseVoice 本地转写模型。本机开发验收时已下载到 SliceAI 独立数据目录；在其他电脑首次使用需要下载。
3. 导入视频；可选添加 UTF-8 编码的 SRT/VTT 字幕和 XML/JSON 弹幕。添加字幕后跳过 ASR。右键素材按钮可移除字幕或弹幕。
4. 选择片段时长、内容偏好、独立片段或合集，点击“开始切片”。
5. 默认完成后自动导出。也可以关闭自动导出，在结果页预览、选择片段再导出。
6. 默认开启“过滤纯播放内容”，需要支持图片输入的模型。结果页点击“已过滤 … 段”或“来源复核”，可查看原因、重新复核；复用已有转写。旧导出文件保留并标记。

## 客户端界面

v0.1.2 默认内容区为 **1090 × 720** 逻辑像素，与本机用户调整后的窗口一致（200% 缩放下为 2180 × 1440 物理像素，不含系统边框）。保留系统标题栏，正常退出时将最近一次普通窗口尺寸保存到独立数据目录的 `window.json`，下次启动恢复；最大化与最小化不会覆盖普通窗口尺寸。

首页为固定的导入区、选项区和两条最近任务；去掉宣传标题和流程说明。结果使用紧凑列表，默认尺寸可完整展示本次 9 个片段；较多结果只在列表内部滚动，导出操作保持可见。推荐理由放在预览中，来源过滤原因放在详情窗口。设置分为 AI 服务、本地转写、导出与偏好三个标签页。支持最小 960 × 640 窗口。

默认在原视频旁的 `SliceAI/录播名称_任务编号/` 保存成片，可以在设置中更改。视频为 H.264 / AAC MP4，附带独立 SRT 字幕，不烧录字幕，不修改原始录播。重复导出使用不同文件名。

## 数据与边界

- 本地 ASR 使用量化 SenseVoice + Silero VAD，音频通过 FFmpeg 流式解码，不生成整场录播的 WAV。
- 精彩内容判断必须调用用户配置的 API，发送转写与可选弹幕文本；默认来源复核还会发送每个候选的 6 张缩略画面，不上传原视频或音频。关闭来源复核后仅分析文本。
- 密钥仅保存在 `%LOCALAPPDATA%/com.sliceai.desktop/sliceai.sqlite3` 中，使用当前 Windows 用户的 DPAPI 加密；界面不会读取回明文密钥。更换 API 服务商地址后需要重新填写密钥。
- 与 BilibiliLive 完全独立：不导入、不读取其密钥、数据库或运行配置，也不调用它的服务。
- 任务串行处理，ASR 子进程转写结束即退出；空闲时不常驻 Python 服务。关闭软件会停止处理，重新打开后可重试中断任务；已导出的文件保留。
- 历史任务、转写、分析结果和缩略图保存在独立数据目录中。当前版本没有缓存清理按钮。
- 单任务最多输出 12 段，可在高级设置中调整到 1–50 段。智能时长范围为 20–360 秒；固定时长为 30–60 秒或 60–180 秒。找不到符合条件的内容时允许没有结果。
- 弹幕 XML 使用 B 站 `d` 节点的 `p` 属性第一项（相对视频秒数）。JSON 支持数组，或 `danmaku` / `comments` 数组：时间字段为 `time` / `start` / `offset` 秒数，或 `progress` 毫秒；文字字段为 `text` / `content`。弹幕可在高级设置中平移 ±600 秒。
- 字幕/JSON 最大 32 MB，弹幕 XML 最多 30 万条。非 UTF-8 文本会明确报错，不会静默转换或覆盖原文件。

## 精彩内容定位

1. 将本地转写或已有字幕标准化为带编号的时间段。
2. 按最多约 8 分钟和 10,500 字符组织重叠文本区间，减少跨边界故事被截断；相邻区间保留约 45 秒上下文。
3. 弹幕按 15 秒统计活跃度，压缩重复刷屏，并提供有上限的文本样本。没有弹幕时只分析转写。
4. API 判断笑点、反转、完整故事、观众互动，并返回原始字幕句子编号及推荐理由。转写和弹幕被明确标记为数据，不作为操作指令。
5. 校验句子编号、先后顺序、时长和录播范围。无效边界不会交给 FFmpeg；执行一次受限的重新请求。
6. 去除重叠片段，优先复核高分候选：抽取片段内 6 张不超过 768 像素宽的画面，结合附近字幕区分主播聊天、外部播放、有实质评论的观看片段及来源不明。没有将固定头像大小或播放器布局作为硬性规则。
7. 仅明确通过的候选进入导出，排除后用后续候选补位。复核预算最多为片段上限的 3 倍且不超过 100 个，未复核候选不导出。正常聊天需有原文与画面证据；观看类片段的评论证据估算至少 10 秒且占片段至少 20%，防止两句吐槽放行几分钟原视频。该保守门槛可能遗漏简短精彩反应。
8. 结果按源文件信息、片段范围、字幕、API 地址/模型和提示版本缓存，导出时重新校验证据。抽帧/API 失败会明确报错，不绕过复核。来源不明或证据无效的片段暂不导出。

当前版本侧重聊天内容，新增候选画面来源识别；未做说话人分离、笑声单独检测或人脸身份分析。发言时长由字幕引用估算，抽帧也可能遗漏画面变化。分数是模型的编辑判断，不是准确率，仍可能误判、漏掉精彩内容。

## 开发

技术组成：Tauri 2 / Rust 原生外壳，Vite + TypeScript 界面，按需启动的 Python 处理引擎，SQLite，sherpa-onnx，FFmpeg。没有常驻 HTTP 后端。

```powershell
python -m venv .venv
.venv/Scripts/python.exe -m pip install -r backend/requirements.txt
npm ci
npm run desktop
```

开发机需要 Rust 的 MSVC 工具链和 Visual Studio C++ Build Tools，FFmpeg / FFprobe 需要在 PATH 中，或在设置中指定。`npm run dev` 只打开浏览器界面预览，实际本地操作需要 `npm run desktop`。

```powershell
npm run build
.venv/Scripts/python.exe -m unittest discover -s tests -v
.venv/Scripts/python.exe scripts/build-worker.py
npm run bundle
.venv/Scripts/python.exe scripts/package-release.py
```

构建脚本从当前系统 PATH 复制独立的 FFmpeg / FFprobe，不从 BilibiliLive 取文件。模型单独下载，不包含在安装包中。第三方组件说明位于 `worker/THIRD-PARTY-NOTICES.txt`。

所有源文本文件均为 UTF-8，无 BOM。设计稿在 `design/`，正式界面入口是根目录 `index.html` 与 `src/`。

## 已完成的验证

- TypeScript 类型检查、Vite 构建、Rust 编译、Windows NSIS 打包。
- 13 项自动测试：UTF-8、字幕与弹幕、长转写覆盖、AI 边界、去重、DPAPI、FFmpeg 取消与导出，以及来源筛选、评论贡献、证据校验、候选补位、缓存失效、旧任务导出拦截与 API 失败处理。
- 打包后的引擎完成了本地 ASR → 隔离的模拟 API → 独立 MP4 / SRT → 合集导出的端到端测试。中文语音由 Windows 本地语音合成生成，没有使用用户录播或外部 API Key。
- 浏览器验收了正式界面及独立测试适配器下的导入、设置、进度、结果、多选、导出选项和实际视频播放。适配器仅在 `.test-artifacts/`，不进入安装包。
- 本机短语音样本测试：26.7 秒音频约 2.5 秒转写完成，转写引擎及 FFmpeg 的采样峰值工作集约 403 MB。该数据仅代表此机器与短样本，不是几小时录播的内存或速度保证。

已使用用户指定的 5 小时 29 分钟真实录播完成整场本地转写与 DeepSeek Flash 实际 API 分析，生成 12 个 MP4 和对应 SRT。实测 117,699 tokens（输入 110,787，输出 6,912），47 次请求包含一次边界修正。完整测试记录见 [测试报告](test-results/2026-08-28/测试报告.md)。转写约 362 秒，处理引擎与 FFmpeg 采样峰值工作集 587 MB；这不包含桌面 UI。桌面空闲时单次测得进程树独占工作集约 250 MB。结果没有逐段人工听校，语音错字、背景音乐及播放视频仍可能影响筛选质量。当前安装包没有代码签名。

v0.1.1 对上述 12 段追加了真实图片 API 复核，排除 3 个以播放外部视频为主的片段，保留 9 段。新增 12 次请求、36,057 tokens，调整本地贡献门槛后复用缓存无新增调用。详见 [来源复核报告](test-results/2026-08-28/来源复核报告.md)。
